# 🏠 House Hunt – Property Listing & Rental Platform

## 📌 Project Overview

House Hunt is a full-stack MERN application designed to help users search, explore, and manage rental or sale properties. The platform provides a seamless experience for property seekers and property owners through an intuitive interface and powerful search capabilities.

## 🎯 Objectives

* Simplify property searching and house hunting.
* Enable property owners to list and manage properties.
* Provide detailed property information with images and pricing.
* Improve user experience through advanced filtering and search.

## ✨ Features

* User Registration & Login
* JWT Authentication & Authorization
* Property Listing Management
* Property Search & Filtering
* Property Details Page
* Image Upload Support
* Responsive User Interface
* User Dashboard
* Favorite/Bookmark Properties
* Secure Backend APIs
